# WebConference

## Sobre o projeto
O WebConference é um projeto de design de uma página web dedicada a uma conferência sobre tecnologia e inovação.

## Objetivo
Apresentar a estrutura e a proposta visual de um website de conferência.

## Materiais de design
- Wireframe: representação simples da estrutura da página.
- Mockup: representação visual com cores, tipografia e elementos gráficos.
